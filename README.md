# the-rtl-compendium
A comprehensive library of digital logic design and RTL building blocks implemented in **Verilog**, **VHDL** and **SystemVerilog**. Covers basic gates, combinational/sequential logic, and memory architectures.
I'm building this compendium to master RTL design across different HDLs while preparing for my VLSI projects and future internships. Every module here has been simulated in **AMD Vivado 2024.2**.
